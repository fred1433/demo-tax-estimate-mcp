A working app for ChatGPT and Claude with two tools: a federal refund estimate that needs no account, and a Save that creates a demo account through OAuth and stores that exact estimate. Filmed in both hosts below, then playable on this page with the same card and the same sign-up.

In Claude and ChatGPT

Add it to your Claude

Add to Claude

Opens Claude's Add custom connector dialog with the name and URL filled in; you confirm there. Server URL: https://tax-mcp-demo.theaipipe.com/mcp/claude.

Add it to your ChatGPT

  1. Open ChatGPT Plugins, select the plus button, then Add custom MCP server.
  2. Server URL: https://tax-mcp-demo.theaipipe.com/mcp/chatgpt
  3. Authentication: OAuth or no authentication. Review the warning, create it, install it, then mention it with @ in a chat.

ChatGPT on the web; workspace permissions for custom MCP servers apply.
